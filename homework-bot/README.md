# Telegram Homework Assistant Bot

**Telegram-бот для автоматического мониторинга статуса проверки домашних заданий через внешнее API.**

**Бот работает в непрерывном фоновом режиме, опрашивает сервер Яндекс Практикума и уведомляет пользователя в чате об изменениях в проверке его работ.**

## 🛠️ Технологический стек
* **Language**: Python 3.9+
* **API Integration**: Requests (взаимодействие с внешним REST API с обработкой HTTP-статусов)
* **Telegram SDK**: pyTelegramBotAPI (Telebot)

## 🚀 Ключевые фичи и архитектура кода

### 🛡️ Обработка ошибок и защита от зацикливания
* **Логика дублирования**: Бот умеет отправлять критические сообщения о сбоях системы (например, если упало API Практикума) прямо тебе в Telegram-чат.
* **Защита от спама**: Внедрен кастомный класс исключений `NotForTelegramError`. Если ломается сам Telegram API или сетевое соединение с ним, бот понимает это, не пытается отправить сообщение в упавший чат (что вызвало бы бесконечную ошибку) и пишет сбой строго в локальный лог.
* **Фильтрация повторов**: Бот запоминает последнюю ошибку (`last_error`) и не шлет в чат одинаковые сообщения при каждом цикле опроса.

### 🧠 Структура функций
* `check_tokens()` — Проверяет наличие обязательных ключей (`PRACTICUM_TOKEN`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`) при старте и завершает процесс, если они не найдены.
* `get_api_answer()` — Делает GET-запросы к эндпоинту, обрабатывает сетевые исключения и проверяет HTTP-статус ответа.
* `check_response()` — Валидирует структуру JSON: проверяет типы данных (словарь/список) и наличие обязательных ключей.
* `parse_status()` — Извлекает имя работы, сопоставляет статус со словарем вердиктов и генерирует текст уведомления.
* `send_message()` — Осуществляет безопасную отправку сообщений в чат.

## 📦 Инструкция по локальному запуску

1. **Клонируйте репозиторий и перейдите в него:**
   ```bash
   git clone https://github.com/vikzolotoy-afk/Practicum_projects.git
   cd Practicum_projects/homework-bot
   ```

2. **Cоздайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/Scripts/activate  # Для Windows
   # source venv/bin/activate    # Для Linux/macOS
   ```

3. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Создайте в корневой директории проекта файл `.env` и укажите ваши секретные токены:
   ```env
   PRACTICUM_TOKEN=ваш_токен_практикума
   TELEGRAM_TOKEN=токен_вашего_телеграм_бота
   TELEGRAM_CHAT_ID=ваш_id_в_телеграм
   ```

5. **Запустите бота:**
   ```bash
   python homework.py
   ```
