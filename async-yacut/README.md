# YaCut — Сервис укорачивания ссылок и асинхронного облачного хранения

Веб-сервис на фреймворке Flask для создания коротких ссылок, асинхронной загрузки файлов в облако Яндекс Диск и автоматического перенаправления пользователей. 
Проект спроектирован в виде пакета и поддерживает как пользовательский веб-интерфейс, так и полноценный REST API.

## 🛠️ Технологический стек
* **Framework**: Flask
* **Asynchronous I/O**: `asyncio`, `aiohttp`
* **Database & ORM**: SQLAlchemy / Flask-Migrate (база данных SQLite)
* **Environment**: Управление конфигурацией через переменные окружения (`python-dotenv`)

## 🚀 Что было реализовано

### 📁 Архитектура и База Данных
* **Модульная структура**: Приложение оформлено в виде пакета с разделением логики на UI, API (`api_views.py`), формы и модели.
* **Модель `URLMap`**: Спроектирована таблица для связывания оригинальных длинных ссылок (`original`) и коротких уникальных идентификаторов (`short`) с фиксацией времени создания.
* **Генерация ID**: Реализована функция `get_unique_short_id()`, генерирующая уникальные короткие маркеры переменной длины на основе алгоритмов модуля `random`.

### 🔗 Веб-интерфейс и Валидация (Flask-WTF)
* **Главная страница (`/`)**: Форма с обязательной валидацией исходного URL и опциональным кастомным идентификатором (до 16 символов).
* **Страница загрузки файлов (`/files`)**: Форма асинхронной отправки файлов на Яндекс Диск через `aiohttp`. При переходе по сгенерированной короткой ссылке автоматически запускается скачивание из облака.
* **Кастомные ошибки**: Написаны индивидуальные обработчики для перехвата ошибок интерфейса и API (обработка 404, 500 и некорректных запросов).

### 🌐 REST API (`api_views.py`)
* Реализованы выделенные эндпоинты для программного взаимодействия с сервисом (генерация и получение оригинальных ссылок через JSON-запросы).

## 📦 Инструкция по локальному запуску

1. **Клонируйте репозиторий и перейдите в него:**
   ```bash
   git clone https://github.com/vikzolotoy-afk/Practicum_projects.git
   cd Practicum_projects/async-yacut
   ```

2. **Cоздайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   ```
   * **Для Linux/macOS:**
     ```bash
     source venv/bin/activate
     ```
   * **Для Windows:**
     ```bash
     source venv/Scripts/activate
     ```

3. **Установите зависимости и обновите pip:**
   ```bash
   python3 -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Создайте файл конфигурации окружения `.env`:**
   В корне проекта создайте файл `.env` и добавьте в него следующие переменные:
   ```env
   FLASK_APP=run.py
   FLASK_ENV=development
   SECRET_KEY=your_secret_key
   DATABASE_URI=sqlite:///db.sqlite3
   DISK_TOKEN=ваш_OAuth_токен_яндекс_диска
   ```

5. **Примените миграции для создания базы данных:**
   ```bash
   flask db upgrade
   ```

6. **Запустите сервер разработки:**
   ```bash
   flask run
   ```
