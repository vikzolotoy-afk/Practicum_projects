# Мое портфолио: Учебные и командные проекты (Python Backend Developer)

 Каждый проект изолирован в своей директории, очищен от системных файлов виртуального окружения и снабжен индивидуальной технической инструкцией.

## 📂 Навигация по каталогу проектов

### 🏆 Дипломный проект
*   **[foodgram](./foodgram)** — «Продуктовый помощник». Полноценный онлайн-сервис и API для публикации рецептов, формирования списков покупок и подписок на авторов. Реализована сложная фильтрация, генерация PDF-документов и контейнеризация.

### 🌐 Web & REST API Development (Django / DRF)
*   **[api-final-yatube](./api-final-yatube)** — Изолированный REST API сервис для социальной сети на Django REST Framework. Настроена `TokenAuthentication` и строгая система прав доступа для авторов контента.
*   **[api-yamdb](./api-yamdb)** — Командный проект платформы отзывов на DRF. Моя зона ответственности: архитектура отзывов/комментариев, кастомные пермишены и защита от дублирования оценок.

### ⚡ Асинхронные сервисы и Микрофреймворки (Flask)
*   **[async-yacut](./async-yacut)** — Сервис укорачивания ссылок на Flask. Реализована **асинхронная загрузка файлов** на Яндекс Диск через библиотеку `aiohttp`, SQLAlchemy ORM и валидация форм через WTForms.

### 🤖 Автоматизация и Боты
*   **[homework-bot](./homework-bot)** — Telegram-бот для мониторинга внешних API. Настроена отказоустойчивая обработка исключений (защита от зацикливания при падении сети) и подробное логгирование.

### 🐳 DevOps & Инфраструктура
*   **[kittygram_final](./kittygram_final)** — Оркестрация многокомпонентного приложения. Написан `docker-compose.yml` для связи бэкенда, фронтенда и базы данных. Настроен CI/CD пайплайн в GitHub Actions с деплоем на удаленный сервер.

## 🛠️ Общий стек технологий в портфолио
* **Languages & Core**: Python 3.9+, ООП, кастомные исключения
* **Frameworks**: Django, Django REST Framework, Flask
* **Asynchronous I/O**: Asyncio, Aiohttp
* **Databases & ORM**: PostgreSQL, SQLite, Django ORM, SQLAlchemy
* **DevOps & Deploy**: Docker, Docker Compose, Nginx, GitHub Actions (CI/CD)
